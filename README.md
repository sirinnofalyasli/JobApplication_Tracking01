# JobApplication_Tracking
It is a web-based career management application that allows users to track job postings and their applications through a single system.


Project Design 
JOBFLOW
│
├── Frontend 🖥️
│   ├── UI
│   ├── Login/Register
│   ├── Dashboard
│   ├── Application list
│   ├── Application create/update
│   ├── Company / Job / Note ekranları
│   └── Backend API bağlantısı
│
└── Backend ☕
    ├── Entity 
    ├── Repository 
    ├── Service 
    ├── Controller 
    ├── Postman CRUD 
    ├── DTO + Validation
    ├── Exception Handling
    ├── Relationships + Business Logic
    ├── Security + JWT
    ├── Tests
    └── Docker
